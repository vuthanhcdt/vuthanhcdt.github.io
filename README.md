# RASL — Robotics and Autonomous Systems Lab

Website: **https://vuthanhcdt.github.io/** · English and Vietnamese (`/vi/`)

## Layout

| Path | What it is |
|---|---|
| `site/` | The published website (static HTML/CSS/JS). GitHub Actions deploys this folder on every push to `master`. |
| `site/assets/members.js` | Lab members and CV data (education, advisors, awards…). `cv.html?m=<id>` builds each CV from it. |
| `site/assets/pubs.js` | Publication list (generated by `tools/pubs.py`). |
| `site/cv.html`, `site/assets/apply.js` | Auto-generated CV page and the student application form. |
| `tools/` | Page generator: section templates (`sec_*.html`), `build.py`, Vietnamese translations (`i18n_vi.py`), publication data (`pubs.py`). |

## Updating the site

```bash
# after editing papers in tools/pubs.py
python3 tools/pubs.py site/assets/pubs.js

# after editing tools/sec_*.html, tools/build.py or tools/i18n_vi.py
python3 tools/build.py "$PWD/site"
```

Then commit and push to `master`; the site is redeployed automatically.
CV, member data and the application form can be edited directly in `site/`.


## Search engines & link previews

- `site/sitemap.xml` and `site/robots.txt` are generated by `build.py`.
- Each page has canonical, `hreflang` (EN/VI) and Open Graph / Twitter card tags.
- Preview images: `site/assets/og-image.png` and `og-image-vi.png`. To change them, edit `tools/og.html` and run `./tools/make_og.sh` (needs Google Chrome).
- Google Search Console: add the property `https://vuthanhcdt.github.io/`, then submit `sitemap.xml`.

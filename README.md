## Overview

This repository hosts the official research group website of the **Robotics and Autonomous Systems Laboratory (RASL)** in the Department of Mechatronics Engineering at Hanoi University of Industry (HAUI).

## Site Structure & Pages

- **`content/_index.md`**: Lab Homepage (Welcome, Vision, Recruiting, Latest News, Core Research Topics).
- **`content/director/index.md`**: Director Biography, Education, Experience, Awards, and Reviewer Services.
- **`content/members/index.md`**: Members Page (Director, Graduate Students, Undergraduate Interns).
- **`content/publications/index.md`**: Filterable Publications Database (14 International Journals and Conferences).
- **`content/news/index.md`**: Lab Announcements and Accepted Papers Timeline.
- **`content/contact/index.md`**: Location, Direct Contact, and Application Guidelines.
- **`static/data/profile-sections.json`**: Dynamic JSON datasets for publications.

## Local Development

```bash

```

Open `http://localhost:1313/` in your web browser.

## Deployment to GitHub Pages

Push to the `master` (or `main`) branch to trigger the automated GitHub Actions deployment workflow (`.github/workflows/hugo.yml`).
